# 🐕 Köpek Lottie Animasyonları

Bu klasör, masaüstündeki köpek pet için Lottie JSON animasyonlarını içerir.

## Gereken dosyalar

| Dosya | Ne yapacak | Önerilen kaynak |
|---|---|---|
| `walk.json` | Yürüyen köpek (loop) | LottieFiles "dog walking" |
| `sit.json` | Oturmuş / kuyruk sallayan köpek (loop) | LottieFiles "dog sitting" |

## Asset nasıl bulunur (3 dakika)

1. https://lottiefiles.com adresine git
2. Arama kutusuna **"dog walking"** yaz
3. Beğendiğin animasyona tıkla
4. Lisans kontrol et — **"Free for commercial use"** olanları seç (çoğu öyle)
5. **"Download"** → **"Lottie JSON"** seçeneği
6. İndirilen dosyayı buraya, **`walk.json`** adıyla koy
7. Aynısını "dog sitting" / "dog idle" için yap, **`sit.json`** adıyla koy

## Önerilen ücretsiz animasyonlar

Aramada şu kelimeler kaliteli sonuçlar verir:
- **"Walking dog cycle"** — pürüzsüz loop için
- **"Puppy idle"** — şirin oturma için
- **"Shiba running"** — bir cinse odaklananlar için

Lottie sanatçısının ismini commit mesajında atıf olarak ekle (örn. "Asset: Walking Dog by John Doe via LottieFiles").

## Boyut

Optimum animasyon ~50-150 KB. 500 KB'tan büyük dosyalar yüklemeyi yavaşlatır.
Çok büyük geliyorsa LottieFiles düzenleyicide gereksiz layer'ları kapatabilirsin.

## Henüz koymadıysan

Sorun değil — köpek görünmez, başka hiçbir özellik etkilenmez. Asset'i koyup sayfayı yenileyince devreye girer.
